LPPO

A feature-rich programming language combining procedural structure with parallel execution

Get Started View on GitHub 
proc main {
    let nums = [1, 2, 3, 4, 5];
    out "Processing array:", nums;
    
    for n in nums {
        if n % 2 == 0 {
            out n, "is even";
        } else {
            out n, "is odd";
        }
    }
    
    parallel {
        out "Parallel execution!";
        out "Running concurrently!";
    }
}

Language Features

Data Types

  • Integers: 42, -17
  • Booleans: true, false
  • Strings: "hello world"
  • Arrays: [1, 2, 3]

Control Flow

  • If/Elif/Else conditionals
  • While loops
  • For-in loops
  • Infinite loops with loop
  • break and continue

Operators

  • Arithmetic: + - * / % **
  • Comparison: == != < > <= >=
  • Logical: and or not
  • Bitwise: & | ^ ~

Advanced Features

  • Array methods: .len()
  • String methods: .upper() .lower() .split()
  • Negative array indexing
  • Procedure parameters
  • Parallel execution blocks

Quick Start

1

Build LPPO

cargo build --release
2

Create a Program

proc main {
    out "Hello from LPPO!";
}
3

Run Your Program

cargo run -- hello.lppo
