# LPPO V5.1 API Reference

**Quick reference for LPPO V5.1 APIs**

This document provides a quick reference for the most commonly used V5.1 APIs. For complete documentation, see [V5.1 Standard Library](V5.1_STDLIB.md).

## Core Language

### Keywords

| Keyword | Purpose | Example |
|---------|---------|---------|
| `proc` | Define procedure | `pub proc main() -> Void` |
| `let` | Declare variable | `let own x: Int64 = 42` |
| `mut` | Mutable qualifier | `let mut own counter: Int64 = 0` |
| `own` | Ownership qualifier | `let own data: Str = "text"` |
| `ref` | Reference qualifier | `let ref borrowed: ref Int64 = ref x` |
| `return` | Return value | `return 42` |
| `if`/`elif`/`else` | Conditionals | `if x > 0 { ... }` |
| `while` | While loop | `while i < 10 { ... }` |
| `for`/`in` | For loop | `for item in items { ... }` |
| `match` | Pattern matching | `match opt { Some(x) => ..., None => ... }` |
| `use` | Import module | `use std::collections::Vec` |
| `pub` | Public visibility | `pub proc test() -> Void` |

### Built-in Types

| Type | Description | Example |
|------|-------------|---------|
| `Int64` | 64-bit signed integer | `let own x: Int64 = 42` |
| `Float64` | 64-bit floating point | `let own pi: Float64 = 3.14` |
| `Float` / `Double` | Alias for `Float64` (language alias) | `let own pi: Float = 3.14159` |
| `Bool` | Boolean | `let own flag: Bool = true` |
| `Str` | String | `let own text: Str = "Hello"` |
| `Void` | No return value | `proc test() -> Void` |
| `Arr<T>` | Array | `let own arr: Arr<Int64> = [1, 2, 3]` |

Notes:
- The bare keyword `Float` and `Double` are treated as aliases for `Float64` (aka `F64`).
- Floating-point literals without a suffix are parsed as 64-bit floats (`F64`). To declare 32-bit floats use `F32` explicitly.

## Collections (std::collections)

### Vec<T>

```lppo
use std::collections::Vec;

// Create
let mut own vec: Vec<Int64> = Vec::new();
let own vec: Vec<Int64> = vec![1, 2, 3];
let own vec: Vec<Int64> = Vec::with_capacity(100);

// Add/remove
vec.push(42);
let own item: Option<Int64> = vec.pop();

// Access
let own first: Option<ref Int64> = vec.first();
let own last: Option<ref Int64> = vec.last();
let own item: Option<ref Int64> = vec.get(0);

// Query
let own len: Int64 = vec.len();
let own is_empty: Bool = vec.is_empty();
let own contains: Bool = vec.contains(42);

// Iterate
for item in vec { ... }
vec.iter().for_each(|x| ...);
```

### HashMap<K, V>

```lppo
use std::collections::HashMap;

// Create
let mut own map: HashMap<Str, Int64> = HashMap::new();

// Add/remove/query
map.insert("key", 42);
let own value: Option<ref Int64> = map.get("key");
let own removed: Option<Int64> = map.remove("key");
let own has_key: Bool = map.contains_key("key");

// Iterate
for (key, value) in map { ... }
```

### HashSet<T>

```lppo
use std::collections::HashSet;

// Create
let mut own set: HashSet<Int64> = HashSet::new();

// Add/remove/query
let own added: Bool = set.insert(42);
let own removed: Bool = set.remove(42);
let own contains: Bool = set.contains(42);

// Set operations
let own union: HashSet<Int64> = set1.union(ref set2);
let own intersection: HashSet<Int64> = set1.intersection(ref set2);
```

## Error Handling

### Result<T, E>

```lppo
// Create
let own success: Result<Int64, Str> = Ok(42);
let own failure: Result<Int64, Str> = Err("error message");

// Query
if result.is_ok() { ... }
if result.is_err() { ... }

// Extract
let own value: Int64 = result.unwrap();
let own value: Int64 = result.unwrap_or(0);
let own value: Int64 = result.expect("message");

// Transform
let own mapped: Result<Int64, Str> = result.map(|x| x * 2);
let own chained: Result<Int64, Str> = result.and_then(|x| Ok(x + 1));

// Error propagation
let own value: Int64 = operation()?; // Returns error if any
```

### Option<T>

```lppo
// Create
let own some: Option<Int64> = Some(42);
let own none: Option<Int64> = None;

// Query
if opt.is_some() { ... }
if opt.is_none() { ... }

// Extract
let own value: Int64 = opt.unwrap();
let own value: Int64 = opt.unwrap_or(0);
let own value: Int64 = opt.expect("message");

// Transform
let own mapped: Option<Int64> = opt.map(|x| x * 2);
let own chained: Option<Int64> = opt.and_then(|x| Some(x + 1));
```

## Iterators

```lppo
use std::collections::Vec;

let own numbers: Vec<Int64> = vec![1, 2, 3, 4, 5];

// Transform
let own doubled: Vec<Int64> = numbers.iter()
    .map(|x| x * 2)
    .collect();

// Filter
let own evens: Vec<Int64> = numbers.iter()
    .filter(|x| x % 2 == 0)
    .collect();

// Aggregate
let own sum: Int64 = numbers.iter().sum();
let own product: Int64 = numbers.iter().product();
let own max: Option<Int64> = numbers.iter().max();
let own min: Option<Int64> = numbers.iter().min();

// Query
let own any_large: Bool = numbers.iter().any(|x| x > 10);
let own all_positive: Bool = numbers.iter().all(|x| x > 0);
let own count: Int64 = numbers.iter().count();

// Take/Skip
let own first_three: Vec<Int64> = numbers.iter().take(3).collect();
let own skip_two: Vec<Int64> = numbers.iter().skip(2).collect();

// Chain operations
let own result: Int64 = numbers.iter()
    .filter(|x| x > 2)
    .map(|x| x * x)
    .sum();
```

## Pattern Matching

```lppo
// Match on Option
match opt {
    Some(x) => out "Value:", x,
    None => out "No value",
}

// Match with guards
match opt {
    Some(x) if x > 100 => out "Large",
    Some(x) if x > 0 => out "Positive",
    Some(0) => out "Zero",
    Some(x) => out "Negative",
    None => out "None",
}

// Match on Result
match result {
    Ok(value) => out "Success:", value,
    Err(error) => out "Error:", error,
}

// Match on tuples
match (x, y) {
    (0, 0) => out "Origin",
    (x, 0) => out "X-axis",
    (0, y) => out "Y-axis",
    (x, y) => out "Point",
}

// Match on enums
match status {
    Status::Success => out "Success",
    Status::Pending => out "Pending",
    Status::Failed(msg) => out "Failed:", msg,
}
```

## Smart Pointers

### Box<T>

```lppo
// Heap allocation
let own boxed: Box<Int64> = Box::new(42);
let own value: Int64 = *boxed; // Dereference
```

### Rc<T>

```lppo
use std::rc::Rc;

// Reference counted (single-threaded)
let own shared: Rc<Str> = Rc::new("shared data");
let own clone1: Rc<Str> = Rc::clone(ref shared);
let own clone2: Rc<Str> = Rc::clone(ref shared);
let own count: Int64 = Rc::strong_count(ref shared); // 3
```

### Arc<T>

```lppo
use std::sync::Arc;

// Atomic reference counted (thread-safe)
let own shared: Arc<Int64> = Arc::new(42);
let own clone: Arc<Int64> = Arc::clone(ref shared);
// Can be shared across threads
```

## Concurrency

### Threads

```lppo
use std::thread;

// Spawn thread
let own handle: JoinHandle<Int64> = thread::spawn(|| {
    return 42;
});

// Wait for completion
let own result: Int64 = handle.join().unwrap();
```

### Channels

```lppo
use std::sync::channel;

// Create channel
let own (tx, rx): (Sender<Int64>, Receiver<Int64>) = channel();

// Send
tx.send(42)?;

// Receive
let own value: Int64 = rx.recv()?;

// Iterate over messages
for msg in rx {
    out "Received:", msg;
}
```

### Mutex

```lppo
use std::sync::Mutex;

// Create mutex
let own mutex: Mutex<Int64> = Mutex::new(0);

// Lock and modify
{
    let mut own guard: MutexGuard<Int64> = mutex.lock().unwrap();
    *guard += 1;
} // Lock released here
```

## Async/Await

```lppo
use std::async;

// Async procedure
pub async proc fetch_data(url: Str) -> Result<Str, Error> {
    let own response: Response = await http::get(url)?;
    let own text: Str = await response.text()?;
    return Ok(text);
}

// Run async code
run_async(async {
    let own result: Result<Str, Error> = await fetch_data("https://example.com");
});

// Concurrent operations
let own (r1, r2) = await join(
    fetch_data("https://api1.example.com"),
    fetch_data("https://api2.example.com")
);
```

## Quick Tips

### Error Handling Pattern

```lppo
pub proc operation() -> Result<Void, Error> {
    let own data: Data = load_data()?;  // ? propagates errors
    process(data)?;
    save_results()?;
    return Ok(());
}
```

### Iterator Chain Pattern

```lppo
let own result: Vec<Int64> = collection
    .iter()
    .filter(|x| x > 0)      // Keep positive
    .map(|x| x * 2)         // Double them
    .take(10)               // First 10
    .collect();             // Collect to Vec
```

### Concurrent Processing Pattern

```lppo
use std::sync::{Arc, Mutex};

let own data: Arc<Mutex<Vec<Int64>>> = Arc::new(Mutex::new(vec![]));

let mut own handles: Vec<JoinHandle<()>> = vec![];
for i in 0..10 {
    let own data_clone: Arc<Mutex<Vec<Int64>>> = Arc::clone(ref data);
    let own handle = thread::spawn(move || {
        let mut own guard = data_clone.lock().unwrap();
        guard.push(i);
    });
    handles.push(handle);
}

for handle in handles {
    handle.join().unwrap();
}
```
