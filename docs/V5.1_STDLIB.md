## Collections

### std::collections::Vec

Dynamic array with automatic resizing.

```lppo
use std::collections::Vec;

// Create empty vector
let mut own vec: Vec<Int64> = Vec::new();

// Create with initial capacity
let mut own vec: Vec<Int64> = Vec::with_capacity(100);

// Create from array literal
let own vec: Vec<Int64> = vec![1, 2, 3, 4, 5];
```

**Methods:**
- `push(item: T)` - Add element to end
- `pop() -> Option<T>` - Remove and return last element
- `len() -> Int64` - Get length
- `capacity() -> Int64` - Get capacity
- `get(index: Int64) -> Option<ref T>` - Safe indexing
- `insert(index: Int64, item: T)` - Insert at position
- `remove(index: Int64) -> T` - Remove at position
- `clear()` - Remove all elements
- `is_empty() -> Bool` - Check if empty
- `iter() -> Iterator<T>` - Create iterator
- `sort()` - Sort in place
- `reverse()` - Reverse in place
- `contains(item: ref T) -> Bool` - Check if contains
- `first() -> Option<ref T>` - Get first element
- `last() -> Option<ref T>` - Get last element

### std::collections::HashMap

Hash table for key-value storage.

```lppo
use std::collections::HashMap;

let mut own map: HashMap<Str, Int64> = HashMap::new();
map.insert("Alice", 30);
map.insert("Bob", 25);

let own age: Option<ref Int64> = map.get("Alice");
```

**Methods:**
- `new() -> HashMap<K, V>` - Create empty map
- `with_capacity(n: Int64) -> HashMap<K, V>` - Create with capacity
- `insert(key: K, value: V) -> Option<V>` - Insert/update key
- `get(key: ref K) -> Option<ref V>` - Get value for key
- `remove(key: ref K) -> Option<V>` - Remove key
- `contains_key(key: ref K) -> Bool` - Check if key exists
- `len() -> Int64` - Get number of entries
- `is_empty() -> Bool` - Check if empty
- `clear()` - Remove all entries
- `keys() -> Iterator<K>` - Iterate over keys
- `values() -> Iterator<V>` - Iterate over values
- `iter() -> Iterator<(K, V)>` - Iterate over key-value pairs

### std::collections::HashSet

Hash set for unique values.

```lppo
use std::collections::HashSet;

let mut own set: HashSet<Int64> = HashSet::new();
set.insert(1);
set.insert(2);
set.insert(2); // Duplicate ignored
```

**Methods:**
- `new() -> HashSet<T>` - Create empty set
- `insert(item: T) -> Bool` - Add item (returns false if already present)
- `remove(item: ref T) -> Bool` - Remove item
- `contains(item: ref T) -> Bool` - Check if contains
- `len() -> Int64` - Get size
- `union(other: ref HashSet<T>) -> HashSet<T>` - Union of sets
- `intersection(other: ref HashSet<T>) -> HashSet<T>` - Intersection
- `difference(other: ref HashSet<T>) -> HashSet<T>` - Difference
- `is_subset(other: ref HashSet<T>) -> Bool` - Check if subset

### std::collections::LinkedList

Doubly-linked list.

```lppo
use std::collections::LinkedList;

let mut own list: LinkedList<Str> = LinkedList::new();
list.push_back("First");
list.push_back("Second");
list.push_front("Zero");
```

**Methods:**
- `push_front(item: T)` - Add to front
- `push_back(item: T)` - Add to back
- `pop_front() -> Option<T>` - Remove from front
- `pop_back() -> Option<T>` - Remove from back
- `front() -> Option<ref T>` - Get first element
- `back() -> Option<ref T>` - Get last element
- `len() -> Int64` - Get length

## String Processing

### std::string

String manipulation utilities.

```lppo
use std::string;

let own s: Str = "Hello, World!";
let own upper: Str = s.to_uppercase();
let own lower: Str = s.to_lowercase();
let own trimmed: Str = s.trim();
```

**String Methods:**
- `len() -> Int64` - Get length in bytes
- `chars() -> Int64` - Get number of characters
- `to_uppercase() -> Str` - Convert to uppercase
- `to_lowercase() -> Str` - Convert to lowercase
- `trim() -> Str` - Remove leading/trailing whitespace
- `split(delim: Str) -> Vec<Str>` - Split by delimiter
- `join(parts: Vec<Str>, sep: Str) -> Str` - Join strings
- `contains(substr: Str) -> Bool` - Check if contains substring
- `starts_with(prefix: Str) -> Bool` - Check prefix
- `ends_with(suffix: Str) -> Bool` - Check suffix
- `replace(from: Str, to: Str) -> Str` - Replace substring
- `substring(start: Int64, end: Int64) -> Str` - Extract substring
- `char_at(index: Int64) -> Option<Char>` - Get character at index

### std::string::StringBuilder

Efficient string building.

## I/O Operations

### std::io::File

File reading and writing.

```lppo
use std::io::File;

// Read file
let own file: File = File::open("data.txt")?;
let own contents: Str = file.read_to_string()?;

// Write file
let own file: File = File::create("output.txt")?;
file.write("Hello, World!")?;
```

**Methods:**
- `open(path: Str) -> Result<File, Error>` - Open for reading
- `create(path: Str) -> Result<File, Error>` - Create/truncate for writing
- `append(path: Str) -> Result<File, Error>` - Open for appending
- `read_to_string() -> Result<Str, Error>` - Read entire file
- `read_to_bytes() -> Result<Vec<Byte>, Error>` - Read as bytes
- `write(data: Str) -> Result<Int64, Error>` - Write string
- `write_bytes(data: Vec<Byte>) -> Result<Int64, Error>` - Write bytes
- `flush() -> Result<Void, Error>` - Flush buffers
- `seek(pos: Int64) -> Result<Int64, Error>` - Seek to position
- `tell() -> Result<Int64, Error>` - Get current position

### std::io::BufReader

Buffered reading.

```lppo
use std::io::{File, BufReader};

let own file: File = File::open("large.txt")?;
let own reader: BufReader = BufReader::new(file);
let own line: Result<Str, Error> = reader.read_line();
```

### std::io::BufWriter

Buffered writing.

```lppo
use std::io::{File, BufWriter};

let own file: File = File::create("output.txt")?;
let mut own writer: BufWriter = BufWriter::new(file);
writer.write_line("First line")?;
writer.write_line("Second line")?;
writer.flush()?;
```

## Networking

### std::net::TcpStream

TCP client.

```lppo
use std::net::TcpStream;

let own stream: TcpStream = TcpStream::connect("127.0.0.1:8080")?;
stream.write("GET / HTTP/1.1\r\n\r\n")?;
let own response: Str = stream.read_to_string()?;
```

### std::net::TcpListener

TCP server.

```lppo
use std::net::TcpListener;

let own listener: TcpListener = TcpListener::bind("127.0.0.1:8080")?;
for connection in listener.incoming() {
    let own stream: TcpStream = connection?;
    handle_client(stream);
}
```

### std::net::UdpSocket

UDP socket.

```lppo
use std::net::UdpSocket;

let own socket: UdpSocket = UdpSocket::bind("127.0.0.1:0")?;
socket.send_to("Hello", "127.0.0.1:8080")?;
```

### std::http

HTTP client/server.

```lppo
use std::http;

// GET request
let own response: Response = http::get("https://api.example.com")?;
let own body: Str = response.text()?;

// POST request
let own data: Str = r#"{"key": "value"}"#;
let own response: Response = http::post("https://api.example.com", data)?;
```

## File System

### std::fs

File system operations.

```lppo
use std::fs;

// Check if exists
let own exists: Bool = fs::exists("file.txt");

// Create directory
fs::create_dir("newdir")?;
fs::create_dir_all("path/to/dir")?;

// Remove file/directory
fs::remove_file("file.txt")?;
fs::remove_dir("dir")?;
fs::remove_dir_all("dir")?;

// Copy/move
fs::copy("src.txt", "dest.txt")?;
fs::rename("old.txt", "new.txt")?;

// Read directory
let own entries: Vec<DirEntry> = fs::read_dir(".")?;
for entry in entries {
    out entry.name();
}

// File metadata
let own metadata: Metadata = fs::metadata("file.txt")?;
out "Size:", metadata.size();
out "Modified:", metadata.modified();
```

### std::path::Path

Path manipulation.

```lppo
use std::path::Path;

let own path: Path = Path::new("/home/user/file.txt");
out "Parent:", path.parent();
out "Filename:", path.filename();
out "Extension:", path.extension();
out "Is absolute:", path.is_absolute();

let own joined: Path = path.join("subdir").join("file.txt");
```

## Error Handling

### std::error::Result

Result type for fallible operations.

```lppo
pub enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

**Methods:**
- `is_ok() -> Bool` - Check if Ok
- `is_err() -> Bool` - Check if Err
- `unwrap() -> T` - Get value or panic
- `unwrap_or(default: T) -> T` - Get value or default
- `expect(msg: Str) -> T` - Get value or panic with message
- `map<U>(f: proc(T) -> U) -> Result<U, E>` - Transform Ok value
- `and_then<U>(f: proc(T) -> Result<U, E>) -> Result<U, E>` - Chain operations

### std::option::Option

Optional value type.

```lppo
pub enum Option<T> {
    Some(T),
    None,
}
```

**Methods:**
- `is_some() -> Bool` - Check if Some
- `is_none() -> Bool` - Check if None
- `unwrap() -> T` - Get value or panic
- `unwrap_or(default: T) -> T` - Get value or default
- `map<U>(f: proc(T) -> U) -> Option<U>` - Transform Some value
- `and_then<U>(f: proc(T) -> Option<U>) -> Option<U>` - Chain operations

## Concurrency

### std::sync::Mutex

Mutual exclusion lock.

```lppo
use std::sync::Mutex;

let own mutex: Mutex<Int64> = Mutex::new(0);
{
    let mut own guard: MutexGuard<Int64> = mutex.lock().unwrap();
    *guard += 1;
} // Lock released here
```

### std::sync::Arc

Atomic reference counting for thread-safe sharing.

```lppo
use std::sync::Arc;

let own shared: Arc<Vec<Int64>> = Arc::new(vec![1, 2, 3]);
let own clone: Arc<Vec<Int64>> = Arc::clone(ref shared);
// Both share the same data
```

### std::sync::Channel

Message passing between threads.

```lppo
use std::sync::channel;

let own (tx, rx): (Sender<Int64>, Receiver<Int64>) = channel();

spawn(|| {
    tx.send(42)?;
});

let own value: Int64 = rx.recv()?;
```

### std::thread

Thread spawning and management.

```lppo
use std::thread;

let own handle: JoinHandle<Int64> = thread::spawn(|| {
    // Thread work
    return 42;
});

let own result: Int64 = handle.join().unwrap();
```

## Async Runtime

### std::async

Asynchronous programming support.

```lppo
use std::async;

pub async proc fetch_data() -> Result<Str, Error> {
    let own response: Response = await http::get("https://api.example.com")?;
    let own text: Str = await response.text()?;
    return Ok(text);
}

pub proc main() -> Void {
    run_async(fetch_data());
}
```

**Async Functions:**
- `await` - Wait for async operation
- `spawn` - Spawn async task
- `join` - Wait for multiple tasks
- `race` - First completed task
- `timeout` - Time-bounded operation
- `select` - Wait on multiple operations
