# LPPO Documentation

Welcome to the LPPO programming language documentation!

## Viewing the Documentation

Open `index.html` in your web browser to view the documentation. You can also serve it with a simple HTTP server:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if you have npx)
npx serve

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.

## Documentation Structure

- **index.html** - Main landing page with overview and quick start
