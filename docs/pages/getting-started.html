Getting Started with LPPO

Learn how to install, build, and run your first LPPO program

Prerequisites

Before you begin, ensure you have the following installed:

  • Rust - Version 1.80 or higher (uses 2021 edition)
  • Cargo - Rust's package manager (comes with Rust)

💡 Installing Rust

If you don't have Rust installed, visit rustup.rs and follow the instructions for your operating system.

Installation

Clone the Repository

git clone https://github.com/BobReed24/LPPO.git
cd LPPO

Build the Project

Build LPPO in release mode for optimal performance:

cargo build --release

The compiled binary will be available at target/release/lppo

✅ Build Complete

If the build completes successfully, you're ready to start writing LPPO programs!

Your First Program

Create a Hello World Program

Create a new file called hello.lppo with the following content:

proc main {
    out "Hello from LPPO!";
    out "Welcome to procedural programming!";
}

Run the Program

Execute your program using Cargo:

cargo run -- hello.lppo

Or use the compiled binary directly:

./target/release/lppo hello.lppo

Expected Output:

Hello from LPPO!
Welcome to procedural programming!

Exploring Features

Variables and Expressions

proc main {
    let x = 10;
    let y = 20;
    let sum = x + y;
    
    out "x =", x;
    out "y =", y;
    out "sum =", sum;
}

Control Flow

proc main {
    let score = 85;
    
    if score >= 90 {
        out "Grade: A";
    } elif score >= 80 {
        out "Grade: B";
    } elif score >= 70 {
        out "Grade: C";
    } else {
        out "Grade: F";
    }
}

Loops and Arrays

proc main {
    let numbers = [1, 2, 3, 4, 5];
    
    out "Array:", numbers;
    out "Length:", numbers.len();
    
    for num in numbers {
        out "Processing:", num;
    }
}

Procedures with Parameters

proc greet(name, age) {
    out "Hello,", name, "!";
    out "You are", age, "years old.";
}

proc main {
    call greet("Alice", 25);
    call greet("Bob", 30);
}

Parallel Execution

proc main {
    out "Starting parallel execution...";
    
    parallel {
        out "Task 1 running";
        out "Task 2 running";
        out "Task 3 running";
    }
    
    out "Parallel execution complete!";
}

Running Example Programs

LPPO comes with several example programs in the examples/ directory:

Hello World

cargo run -- examples/hello.lppo

Comprehensive Features Demo

cargo run -- examples/comprehensive.lppo

Loop Examples

cargo run -- examples/loops.lppo

Operator Demonstrations

cargo run -- examples/operators.lppo

Compiling to Standalone Executable

You can compile your LPPO program into a standalone executable that includes the runtime:

cargo run -- --compile-out myprogram.exe hello.lppo

Then run your standalone executable:

./myprogram.exe

📦 Binary Bundling

The bundled executable contains both your compiled LPPO program and the runtime, making it easy to distribute your programs without requiring users to have LPPO installed.

Debug Mode

Enable diagnostic output to see compilation and execution details:

cargo run -- --debug hello.lppo

Debug mode shows:

  • Tokenization output
  • Abstract Syntax Tree (AST)
  • Compiled operations
  • Execution flow
