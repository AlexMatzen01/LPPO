Data Types

LPPO supports four fundamental data types:

Integer

Whole numbers, positive or negative:

let x = 42;
let y = -17;
let z = 0;

Boolean

Logical true/false values:

let is_valid = true;
let is_empty = false;

String

Text enclosed in double quotes:

let name = "Alice";
let message = "Hello, World!";
let multiline = "Line 1\nLine 2";

Escape Sequences

Sequence Meaning
\n Newline
\r Carriage return
\t Tab
\\ Backslash
\" Double quote

Array

Ordered collections of values:

let numbers = [1, 2, 3, 4, 5];
let names = ["Alice", "Bob", "Charlie"];
let mixed = [1, "two", 3, "four"];

Variables

Variables are declared using the let keyword:

let x = 10;
let name = "LPPO";
let items = [1, 2, 3];

📝 Variable Assignment

Variables in LPPO are reassignable. You can change their value by using another let statement with the same name.

let count = 0;
let count = count + 1;  // count is now 1
let count = count + 1;  // count is now 2

Operators

Arithmetic Operators

Operator Description Example
+ Addition 5 + 3 → 8
- Subtraction 5 - 3 → 2
* Multiplication 5 * 3 → 15
/ Division 6 / 3 → 2
% Modulo (remainder) 5 % 3 → 2
** Power 2 ** 8 → 256

Comparison Operators

Operator Description Example
== Equal to 5 == 5 → true
!= Not equal to 5 != 3 → true
< Less than 3 < 5 → true
> Greater than 5 > 3 → true
<= Less than or equal 3 <= 5 → true
>= Greater than or equal 5 >= 5 → true

Logical Operators

Operator Description Example
and Logical AND true and false → false
or Logical OR true or false → true
not Logical NOT not true → false

Bitwise Operators

Operator Description Example
& Bitwise AND 5 & 3 → 1
| Bitwise OR 5 | 3 → 7
^ Bitwise XOR 5 ^ 3 → 6
~ Bitwise NOT ~5 → -6

Operator Precedence

Operators are evaluated in the following order (highest to lowest):

  1. Unary operators: -, !, ~
  2. Power: **
  3. Multiplicative: *, /, %
  4. Additive: +, -
  5. Bitwise: &, |, ^
  6. Comparison: ==, !=, <, >, <=, >=
  7. Logical AND: and
  8. Logical OR: or

Use parentheses () to override precedence:

let result = (5 + 3) * 2;  // 16, not 11

Control Flow

If Statement

if condition {
    // code executed if condition is true
}

If-Else Statement

if condition {
    // code executed if condition is true
} else {
    // code executed if condition is false
}

If-Elif-Else Chain

if condition1 {
    // executed if condition1 is true
} elif condition2 {
    // executed if condition1 is false and condition2 is true
} elif condition3 {
    // executed if condition1 and condition2 are false and condition3 is true
} else {
    // executed if all conditions are false
}

Example

let score = 85;

if score >= 90 {
    out "Excellent!";
} elif score >= 80 {
    out "Very Good!";
} elif score >= 70 {
    out "Good!";
} else {
    out "Keep trying!";
}

Loops

While Loop

Executes while a condition is true:

let i = 0;
while i < 5 {
    out "Count:", i;
    let i = i + 1;
}

For-In Loop

Iterates over elements in an array:

let items = [10, 20, 30, 40, 50];
for item in items {
    out "Item:", item;
}

Infinite Loop

Loops forever until explicitly broken:

let count = 0;
loop {
    out "Iteration:", count;
    let count = count + 1;
    if count >= 5 {
        break;
    }
}

Loop Control

Break

Exits the current loop immediately:

let i = 0;
while i < 10 {
    if i == 5 {
        break;  // exits loop when i is 5
    }
    out i;
    let i = i + 1;
}

Continue

Skips the rest of the current iteration and continues with the next:

let i = 0;
while i < 10 {
    let i = i + 1;
    if i % 2 == 0 {
        continue;  // skips even numbers
    }
    out "Odd:", i;
}

Arrays

Creating Arrays

let empty = [];
let numbers = [1, 2, 3, 4, 5];
let mixed = [1, "two", 3, "four"];

Array Indexing

Access elements using square brackets:

let arr = [10, 20, 30, 40, 50];

out arr[0];   // First element: 10
out arr[2];   // Third element: 30
out arr[4];   // Last element: 50

Negative Indexing

Access elements from the end of the array:

let arr = [10, 20, 30, 40, 50];

out arr[-1];  // Last element: 50
out arr[-2];  // Second-to-last: 40
out arr[-5];  // First element: 10

Array Methods

.len()

Returns the number of elements:

let arr = [1, 2, 3, 4, 5];
out arr.len();  // Output: 5

Array Concatenation

Combine arrays using the + operator:

let arr1 = [1, 2, 3];
let arr2 = [4, 5, 6];
let combined = arr1 + arr2;
out combined;  // [1, 2, 3, 4, 5, 6]

Strings

Creating Strings

let greeting = "Hello, World!";
let name = "LPPO";
let multiline = "Line 1\nLine 2\nLine 3";

String Indexing

Access individual characters:

let text = "Hello";
out text[0];   // "H"
out text[4];   // "o"
out text[-1];  // "o" (last character)

String Methods

.len()

Returns the string length:

let text = "Hello";
out text.len();  // Output: 5

.upper()

Converts to uppercase:

let text = "hello";
out text.upper();  // Output: HELLO

.lower()

Converts to lowercase:

let text = "HELLO";
out text.lower();  // Output: hello

.split(separator)

Splits string into an array:

let csv = "apple,banana,cherry";
let fruits = csv.split(",");
out fruits;  // ["apple", "banana", "cherry"]

String Concatenation

Combine strings using the + operator:

let first = "Hello";
let second = "World";
let combined = first + " " + second;
out combined;  // "Hello World"

Procedures

Defining Procedures

proc procedure_name {
    // procedure body
}

Procedures with Parameters

proc greet(name, age) {
    out "Hello,", name;
    out "You are", age, "years old";
}

Calling Procedures

call procedure_name;
call greet("Alice", 25);

The Main Procedure

Every LPPO program must have a main procedure as the entry point:

proc main {
    out "Program starts here";
    call other_procedure;
}

proc other_procedure {
    out "This is another procedure";
}

Complete Example

proc calculate(a, b) {
    let sum = a + b;
    let product = a * b;
    let difference = a - b;
    
    out "Sum:", sum;
    out "Product:", product;
    out "Difference:", difference;
}

proc main {
    call calculate(10, 5);
    call calculate(20, 8);
}

Parallel Execution

LPPO supports native parallel execution using parallel blocks:

proc main {
    out "Starting parallel tasks...";
    
    parallel {
        out "Task 1 executing";
        out "Task 2 executing";
        out "Task 3 executing";
    }
    
    out "All parallel tasks complete!";
}

⚡ Parallel Execution

Statements inside a parallel block execute concurrently using threads. The order of execution is not guaranteed. The program waits for all parallel tasks to complete before continuing.

Practical Example

proc process(id) {
    out "Processing task", id;
}

proc main {
    parallel {
        call process(1);
        call process(2);
        call process(3);
        call process(4);
    }
    out "All processing complete";
}

Comments

Line Comments

Start with // and continue to the end of the line:

// This is a single-line comment
let x = 10;  // Comment at end of line

Block Comments

Enclosed between /* and */:

/*
   This is a multi-line comment
   It can span multiple lines
   Useful for documentation
*/

let x = 10;

Output Statement

The out statement prints values to stdout:

Single Value

out "Hello";

Multiple Values

Separate values with commas:

out "x =", x, "y =", y;

Arrays and Complex Values

let arr = [1, 2, 3];
out "Array:", arr;  // Output: Array: [1, 2, 3]

Input Statement

The input statement reads user input from stdin with explicit type specification:

Syntax

input variable_name: Type;                    // Basic input
input variable_name: Type with prompt_expr;   // Input with prompt

String Input

pub proc main() -> Void {
    input name: Str with "Enter your name:";
    out "Hello,", name;
}

Integer Input

pub proc main() -> Void {
    input age: Int64 with "Enter your age:";
    let own double: Int64 = age + age;
    out "Double:", double;
}

Boolean Input

pub proc main() -> Void {
    input flag: Bool with "Continue? (yes/no):";
    let own yes_msg: Str = "Continuing...";
    let own no_msg: Str = "Stopping...";
    
    if flag {
        out yes_msg;
    } else {
        out no_msg;
    }
}

Boolean input accepts: true, false, yes, no, y, n, 1, 0 (case-insensitive)

Array Input

pub proc main() -> Void {
    // Accepts: "1,2,3" or "[1, 2, 3]"
    input numbers: Arr with "Enter numbers:";
    out "You entered:", numbers;
    
    let mut own total: Int64 = 0;
    for num: Int64 in numbers {
        let own new_total: Int64 = total + num;
        move new_total -> total;
    }
    out "Sum:", total;
}

⚠️ Input Validation

All input is validated according to the specified type. Type mismatches produce descriptive error messages and terminate the program.
